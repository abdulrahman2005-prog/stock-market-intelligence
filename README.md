# Stock Market Analysis Dashboard

## Project Overview

This project analyzes the historical stock performance of five major technology companies:

- Apple (AAPL)
- Microsoft (MSFT)
- NVIDIA (NVDA)
- Amazon (AMZN)
- Tesla (TSLA)

The project covers the complete data analysis workflow, including data cleaning, exploratory data analysis, risk analysis, performance evaluation, and the development of an interactive dashboard using Streamlit.

---

## Project Objectives

The main objectives of this project are:

- Clean and prepare historical stock price data.
- Analyze stock closing prices.
- Compare the performance of multiple companies.
- Calculate daily returns.
- Measure investment risk using volatility and return distributions.
- Analyze the relationship between stock returns.
- Calculate cumulative returns.
- Evaluate risk-adjusted performance using the Sharpe Ratio.

- Build an interactive dashboard for easier visualization and analysis.

## Risk Analysis

Several metrics were used to evaluate investment risk.

### Volatility

Annualized volatility measures the variability of stock returns.

Higher volatility generally indicates greater price fluctuations and higher investment risk.

The annualized volatility was calculated using:

```python
annual_volatility = daily_returns.std() * np.sqrt(252)
```

### Kurtosis

Kurtosis was used to analyze extreme movements in daily returns.

Higher kurtosis may indicate heavier tails and a greater probability of extreme return events.

### Maximum Drawdown

Maximum Drawdown measures the largest decline from a previous peak.

It was calculated by comparing stock prices with their historical maximum values.

A larger negative Maximum Drawdown indicates greater downside risk.

---

## Performance Analysis

### Cumulative Return

Cumulative Return measures the total return generated by a stock during the analysis period.

It was calculated using:

```python
cumulative_return = (
    (df.iloc[-1] / df.iloc[0]) - 1
) * 100
```

The cumulative return analysis showed the overall historical performance of each company.

### Annualized Return

Annualized Return estimates the yearly return based on average daily returns.

```python
annual_return = daily_returns.mean() * 252
```

### Sharpe Ratio

The Sharpe Ratio measures risk-adjusted performance.

It compares the expected return with the level of risk taken.

```python
sharpe_ratio = annual_return / (
    daily_returns.std() * np.sqrt(252)
)
```

A higher Sharpe Ratio generally indicates better risk-adjusted performance.

### Risk vs Return

A Risk vs Return analysis was performed to compare:

- Annualized Return
- Annualized Volatility

This visualization helps identify companies with potentially better returns relative to their level of risk.
